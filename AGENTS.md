# AGENTS.md

Static marketing site — the preset's DB/auth rules do not apply.

## Project

- Next.js App Router, TypeScript, Tailwind CSS v3.
- No database, no authentication, no server mutations.
- Public pages are static; keep them statically renderable.
- Content lives in typed constants under `src/content/`.
- Package manager: pnpm. Use `pnpm install`, `pnpm lint`, `pnpm build`.
- Turkish-first copy; the HTML language is `tr`.
